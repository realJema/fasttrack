# FastTrack - Intermittent Fasting

Offline-first intermittent fasting tracker built with Expo SDK 58 (expo-router, TypeScript). All data lives on the device via AsyncStorage - no accounts, no servers.

Commands:
- npm start or npx expo start - run the dev server
- npx tsc --noEmit - typecheck
- npx eslint src - lint

Screens: Home (timer ring, tips, quick-start checklist), Fasting plan wizard, Analytics, Explore, Profile
